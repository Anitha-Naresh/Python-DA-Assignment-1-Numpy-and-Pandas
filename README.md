Python Data Analytics Assignment 1 – NumPy and Pandas
Overview

This assignment focuses on performing data analysis using NumPy and Pandas.

The main objective of this assignment is to understand numerical computation, data manipulation, data exploration, indexing, slicing, filtering, and aggregation using Python libraries.

Assignment Objectives

The assignment covers:

Working with NumPy arrays for numerical computations
Creating and manipulating Pandas Series
Creating and analyzing Pandas DataFrames
Applying indexing and slicing techniques
Filtering data using conditions
Performing aggregation and grouping operations
Understanding data handling using real-world temperature and transaction datasets
1. NumPy Array Operations

Temperature data for two weeks is analyzed using NumPy.

The assignment includes:

Creating a one-dimensional array for Week 1 temperatures
Inspecting the shape, data type, and number of elements
Converting temperatures from Celsius to Fahrenheit
Finding the maximum temperature
Finding the minimum temperature
Calculating the mean temperature
Extracting the first three days
Extracting the weekend temperatures
Extracting the middle three days
2. Two-Dimensional NumPy Array

A two-dimensional array is created containing temperature data for two weeks.

The assignment includes:

Creating a two-dimensional temperature array
Inspecting its shape
Inspecting its data type
Finding the total number of elements
Extracting temperatures for each week
Extracting weekend temperatures for both weeks
3. Pandas Series

A Pandas Series containing student marks and custom rank labels is created.

The assignment includes:

Creating a Series with student marks
Using custom index labels
Accessing values using integer positions
Using the loc method to select specific ranks
Using the iloc method to access values by position
Filtering marks greater than 90
Modifying the first-rank student's mark
Removing the last-rank entry
Calculating CGPA from the marks
4. Pandas DataFrame

A transaction dataset containing transaction IDs, product categories, regions, and transaction amounts is created and analyzed.

The assignment includes:

Creating a transaction DataFrame
Displaying the DataFrame
Viewing the first and last records
Checking the shape of the DataFrame
Viewing column names
Checking data types
Displaying basic DataFrame information
Selecting specific columns
Retrieving the last three columns
Filtering transactions based on region and amount
Finding product category counts
Finding unique regions
Calculating the average transaction amount for each region
5. DataFrame Manipulation

The transaction DataFrame is further modified.

The assignment includes:

Updating the transaction amount for Transaction ID 102
Adding a Discount column based on the transaction amount
Removing the transaction with Transaction ID 109
Deleting the Discount column
